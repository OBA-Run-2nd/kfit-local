K-Fit & Local
팀 공유용 기획안 초안

1. 서비스 개요

외국인 관광객이 사진과 모국어로 원하는 F&F 상품을 찾고, 색상과 사이즈를 선택해 실제 매장 시착으로 연결하는 모바일 웹 서비스.

고객은 매장에서 원하는 상품과 착용감을 설명하는 부담을 줄이고, F&F는 고객의 취향과 실제 시착 결과를 파악할 수 있다.

핵심 목표: 온라인 상품 탐색 → 오프라인 매장 방문 → 시착·구매 연결


2. 기획 배경과 주요 타깃

[오프라인 구매 선호에 대한 기획 가설]
외국인 관광객은 의류의 사이즈와 착용감을 직접 확인할 수 있는 오프라인 구매를 선호할 것이라는 가설에서 출발한다. 특히 국가별 사이즈 표기와 개인별 희망 핏의 차이 때문에, 온라인에서 관심 상품을 찾고 한국 매장에서 직접 입어본 뒤 구매하려는 고객을 주요 타깃으로 한다.

이는 외국인 전체에 대해 확인된 사실로 단정하지 않는다. 관광객·매장 직원 인터뷰와 시착 테스트를 통해 선호도와 실제 불편을 검증한다.

[주요 타깃]
한국 여행 중 F&F 상품에 관심이 있고, 사이즈와 착용감을 직접 확인한 뒤 구매하려는 외국인 관광객.

[해결할 문제]
- 원하는 스타일과 착용감을 한국어로 설명하기 어렵다.
- 상품별 색상·사이즈가 어느 매장에 있는지 확인하기 번거롭다.
- 여러 상품을 입어보고 싶을 때 직원에게 각각 설명해야 한다.
- 브랜드는 고객이 원한 스타일과 실제 구매하지 않은 이유를 파악하기 어렵다.


3. 서비스 이용 흐름

사진·모국어 입력 → 상품 추천 → 시착 목록 담기 → 매장 선택 → QR로 직원에게 전달 → 시착 결과 확인 → 선택적으로 미션 참여

① 원하는 상품·스타일 입력
F&F 상품 사진을 올리거나 상품을 선택하고, 모국어로 취향과 원하는 착용감을 입력한다.

예시:
“이런 밝은색 상의를 찾고 있어요. 로고가 작고 몸에 붙지 않았으면 좋겠어요. S와 M을 비교해서 입어보고 싶어요.”

② 추천 상품 확인
사진과 입력 조건을 바탕으로 유사한 F&F 상품 Top 3를 보여준다.
상품 사진·가격·선택 가능한 옵션과 함께, 요청한 스타일과 비슷한 점 및 다른 점을 안내한다. 조건에 맞는 상품이 부족하면 그 사실을 알린다.

③ 시착 목록 담기
관심 상품 여러 개를 색상·희망 사이즈와 함께 저장한다. 원하는 착용감이나 비교하고 싶은 사이즈도 남긴다.
사이즈 판단 근거가 부족한 경우에는 적합한 사이즈라고 단정하지 않고, 비교 시착할 사이즈를 선택하게 한다.

④ 방문할 매장 선택
가까운 매장과 함께 담은 상품을 얼마나 입어볼 수 있는지 보여준다.

예시:
- A 매장: 담은 상품 3개 중 1개 재고 확인
- B 매장: 담은 상품 3개 모두 재고 확인

매장 위치·길찾기·재고 확인 시점을 제공한다. 재고가 확인되지 않은 상품은 별도로 표시한다.

⑤ QR 시착 패스 전달
선택한 목록으로 QR을 생성한다. 고객이 매장에서 QR을 보여주면 직원은 한국어 화면에서 상품과 요청을 확인한다.

직원 화면:
- 상품 사진·품번
- 색상·시착 희망 사이즈
- 원하는 착용감
- 준비 가능 여부

직원은 ‘확인 중 / 준비 가능 / 품절·대안 필요’ 상태를 안내한다. QR 사용이 어려운 경우에는 같은 내용을 상품 카드로 보여준다.

⑥ 시착 결과 확인
시착 후 간단한 피드백을 받는다.
- 착용감: 잘 맞음 / 작음 / 큼 / 원하는 핏과 다름
- 구매 여부
- 미구매 이유: 사이즈 / 디자인 / 가격 / 재고 / 기타

⑦ 문화 미션·프로모션 참여
고객이 원하면 상품이나 매장 주변과 연결된 문화 체험·프로모션에 참여한다.

예시:
- 선택한 스타일로 여행 사진 남기기
- 주변 문화 공간 방문
- 매장 행사 참여
- 구매한 옷과 여행 사진을 룩북으로 저장

구체적인 체험과 혜택은 운영 가능한 범위에서 정한다. 미션은 상품 탐색과 시착 요청을 방해하지 않는 선택 기능으로 제공한다.


4. 핵심 기능

- 사진·다국어 탐색: 사진과 모국어 요청으로 유사 상품 추천
- 시착 목록: 여러 상품의 색상·사이즈·착용감 요청 저장
- 매장·재고 안내: 목록의 재고 충족 여부, 위치와 길찾기 제공
- QR 시착 패스: 고객 목록을 직원용 한국어 화면으로 전달
- 직원 확인: 준비 가능·품절·대안 필요 상태 안내
- 시착 피드백: 실제 착용 결과와 구매·미구매 이유 확인
- 미션·프로모션: 선택형 문화 체험과 행사 참여


5. 고객과 F&F가 얻는 가치

[고객]
- 모국어로 취향과 시착 요청 전달
- 여러 상품을 한 번에 정리
- 방문 전 관심 상품의 재고 확인
- 매장 내 설명 부담과 불필요한 이동 감소
- 구매 전 직접 착용하며 사이즈와 핏 비교

[F&F]
- 고객이 표현한 스타일·착용감 선호 파악
- 선택 사이즈와 실제 착용 결과 비교
- 구매로 이어지지 않은 이유 확인
- 상품과 문화 체험·프로모션의 반응 분석
- 향후 상품 제안·매장 운영·제품 기획에 활용

매출·수익 개선은 기대 효과이며, 실제 구매 전환과 운영·프로모션 비용을 통해 검증한다.


6. 데이터 활용 방향

- 자연어 요청과 선택 상품: 고객이 원하는 색상·핏·스타일 분석
- 희망 사이즈와 시착 피드백: 요청한 사이즈와 실제 착용 결과의 차이 확인
- 시착·구매 결과: 관심이 실제 행동으로 이어지는 흐름 확인
- 미구매 이유: 사이즈·디자인·가격·재고 등 구매 장애 요인 파악
- 미션 선택·완료 지점·혜택 사용: 어떤 상품과 체험이 함께 선택되는지 분석

선택한 사이즈를 실제 적합 사이즈로 해석하지 않는다. 미션 완료 지점은 참여 장소를 뜻하며, 여행 전체 이동 경로를 의미하지 않는다.
분석용 정보의 수집 목적과 선택 참여 범위를 알기 쉽게 안내한다.


7. 초기 구현 범위와 운영 확인 사항

한 브랜드·일부 상품·소수 매장을 대상으로 핵심 흐름을 완성한다. 미션은 간단한 예시부터 적용한다.

- 실제 재고를 받을 수 있는지 확인한다.
- 직원이 QR을 확인할 기기와 응대 방식을 정한다.
- 재고 조회와 상품 예약·확보를 구분한다.
- QR 생성·직원 확인·시착·구매를 각각 구분해 기록한다.
- 데모 데이터와 실제 연동 데이터를 명확히 표시한다.

초기 진입 경로 후보:
F&F 온라인 상품 페이지·스타일 콘텐츠에서 ‘매장에서 입어보기’로 연결한다. 실제 제공 가능한 채널은 별도 확인한다.


8. 우선 검증할 가설

- 타깃 외국인 관광객이 의류 구매 시 직접 입어보는 과정을 얼마나 중요하게 생각하는가?
- 고객이 기존 방식보다 쉽게 상품을 찾고 시착을 요청할 수 있는가?
- 직원이 상품과 원하는 착용감을 더 정확하게 파악하는가?
- 목록 기준 재고 안내가 매장 선택과 방문에 도움이 되는가?
- 시착 피드백이 브랜드의 상품·사이즈 문제 파악에 유용한가?
