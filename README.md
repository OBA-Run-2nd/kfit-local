# K-Fit & Local — F&F 콘셉트 데모

React + Vite로 만든 프런트엔드 시연입니다. PC 웹과 앱 형태의 모바일 웹에서 같은 기능을 사용할 수 있습니다.

## 실행

```powershell
cd "C:\Users\giuny\Desktop\react-demo"
npm.cmd run dev
```

터미널에 표시된 Local 주소를 엽니다. 기본 포트가 사용 중이면 Vite가 다른 포트를 표시하므로 실제 출력 주소를 사용하세요.

- PC 웹: `http://localhost:5173/#/web/home`
- 모바일 앱 시연: `http://localhost:5173/#/app/home`
- 직원 화면: `http://localhost:5173/#/web/staff`

상단의 PC 웹 / 모바일 앱 / 직원 화면 버튼으로 전환할 수 있습니다. 모바일 앱은 설치형 네이티브 앱이 아니라 브라우저에서 동작하는 앱 형태의 모바일 웹입니다.

## 카카오톡으로 HTML 파일 하나 보내기

```powershell
npm.cmd run export:html
```

프로젝트 폴더에 생성되는 `K-Fit_Local_공유용.html` 파일 하나를 보내면 됩니다. 받은 사람은 파일을 다운로드해 Chrome 또는 Edge 등 최신 브라우저로 엽니다. Node.js 설치, 터미널 명령, 별도 서버가 필요하지 않습니다.

- React 실행 코드·CSS·상품 SVG·QR·아이콘이 파일 안에 포함됩니다.
- 외부 여행 사진은 인터넷 연결 시 표시되며, 로드에 실패하면 기본 그래픽을 표시합니다. 공유 파일은 시스템 글꼴을 사용합니다.
- 외부 지도와 공식 관광 안내를 여는 기능은 인터넷 연결이 필요합니다.
- 각자의 브라우저 안에서 체험하는 데모이므로 서로의 시착 목록이나 쿠폰이 공유되지 않습니다. 로컬 파일 저장을 제한하는 브라우저에서는 기록 유지가 제한될 수 있습니다.
- 수정한 내용을 보내려면 명령을 다시 실행해 새 HTML 파일을 전달하세요. 이미 보낸 파일은 자동으로 갱신되지 않습니다.

## 구현 기능

- 6개 브랜드·30개 시연 상품, 브랜드/카테고리 필터, 상품 검색, 가격 정렬, 찜
- 상품 상세 모달, 색상·사이즈 선택, 착용감 메모, 시착 목록 수정·삭제
- 스타일 사진 업로드 미리보기와 샘플 스타일
- 자연어 키워드·브랜드·카테고리·사이즈·예산을 이용한 더미 Top 3 추천
- 선택한 브랜드와 상품 옵션별 더미 재고, 지역·거리·재고 기준 매장 정렬
- 시연 지도와 실제 Google Maps의 지역 검색 링크
- 현장 QR 조회 시연, 상품별 진열·창고 위치와 사이즈별 재고, 상품 찾기 체크리스트
- 상품별 시착 피드백, 구매 여부·미구매 이유
- 한국 가이드: 서울·부산·제주·경주·전주의 여행 체험을 지역 선택 없이 섞어서 제공
- 장소별 할 일 3가지, 예상 소요 시간, 여행 팁, 공식 관광 안내와 Google Maps 길찾기
- 선택형 미션 참여·완료, 메모와 여행 사진 미리보기, 완료 시 데모 쿠폰 발급
- 쿠폰함: 할인 금액·최소 구매 금액·유효 기간·사용 시연, 중복 발급 방지
- 한국어·영어·번체 중국어 전환
- 브라우저 내 기록 저장, 데모 초기화

## 추천 시연 순서

1. PC 웹에서 브랜드와 컬렉션을 둘러봅니다.
2. 스타일 찾기에서 샘플 스타일을 선택합니다.
3. “밝은색의 여유 있는 자켓을 찾고 있어요”라고 입력하고 추천 결과를 확인합니다.
4. 상품 상세에서 색상과 M 사이즈를 선택하고 시착 목록에 담습니다.
5. 목록에서 옵션을 확인하고 매장 찾기로 이동합니다.
6. 선택 브랜드의 옵션별 재고를 확인하고 매장 패스를 생성합니다.
7. 직원 화면에서 “고객 QR 읽기 시연”을 누릅니다. 상품별 진열 위치·창고 선반·수량과 사이즈별 재고를 확인합니다. 상품 찾기 또는 품절 대안 안내를 체크한 뒤 전달 완료를 누릅니다.
8. 시착 피드백과 미구매 이유를 남깁니다.
9. 한국 가이드에서 여러 도시의 체험을 둘러봅니다. 장소별 할 일과 팁을 읽고 길찾기 또는 공식 관광 안내를 열 수 있습니다. 각 카드는 별도의 여행 아이디어이며 도시를 잇는 하나의 당일 코스가 아닙니다.
10. 원하는 체험의 “여행 기록 남기기”를 눌러 참여하고 메모·사진을 추가한 뒤 완료하면 쿠폰이 발급됩니다. “내 쿠폰함”에서 발급 내역과 사용 시연을 확인합니다.
11. 모바일 앱 버튼으로 전환해 같은 기능을 앱 화면에서 확인합니다.

## 더미 데이터와 한계

- AI 모델, 백엔드, 서버 DB, 실제 주문·결제·예약 기능은 없습니다.
- 추천은 준비된 상품 데이터와 간단한 로컬 규칙으로 동작합니다. 사진 픽셀을 분석하거나 외부 서버에 전송하지 않습니다.
- 상품명·가격·옵션·상품 일러스트는 시연용입니다. 실제 F&F 판매 상품이나 가격으로 해석하면 안 됩니다.
- 매장 위치·영업시간·거리·재고는 모두 가상 데이터입니다. 여러 브랜드가 한 매장에 있는 것으로 오해하지 않도록 브랜드별로 시착 패스를 생성합니다.
- 지도는 시연용 지역 그림입니다. 길찾기 링크는 실제 매장 주소가 아닌 해당 지역의 Google Maps 검색을 엽니다.
- QR은 `KF-DEMO-0001`이라는 시연 식별자를 담은 실제 QR입니다. 카메라와 서버 연결은 구현하지 않았습니다. 같은 브라우저에서 “고객 QR 읽기 시연” 또는 코드 입력으로 현장 조회를 시연합니다. 패스를 생성해도 직원 화면에는 상품이 미리 표시되지 않습니다.
- 진열·창고 수량의 합계는 고객 화면의 동일 상품·색상·사이즈 재고와 일치합니다. 상품 찾기 체크는 실제 재고를 차감하지 않습니다.
- 시착 목록·직원 상태·피드백·미션·쿠폰은 이 브라우저의 localStorage에만 저장됩니다. 다른 기기와 공유되지 않습니다.
- 업로드 사진은 화면 미리보기용이며 새로고침·화면 이동 후 보존되지 않습니다. 미션의 완료 여부와 메모는 저장됩니다.
- 미션 완료는 사용자가 누르는 시연 동작입니다. 완료 시 미션당 데모 쿠폰 1장이 발급되고 새로고침 후에도 유지됩니다. 실제 방문 인증이나 매장 할인 적용은 없습니다. 쿠폰 금액·조건·기한은 기획 예시이며 F&F의 실제 프로모션이 아닙니다.
- 관광 장소의 개요는 VISITKOREA 공식 안내를 참고했습니다. 예상 체험 시간과 3단계 즐길 거리는 데모의 편집 제안이며, 실시간 혼잡도나 최신 영업 정보를 제공하지 않습니다. 카드의 공식 안내에서 방문 조건을 확인할 수 있습니다.
- 여행 카드 사진은 여행 분위기를 위한 Unsplash 이미지이며 해당 장소의 실제 사진임을 보장하지 않습니다.
- 직원 화면은 상품·옵션을 한국어로 표시합니다. 자유 입력 메모의 실시간 번역은 연결하지 않았습니다.
- 외부 편집 사진은 Unsplash, 웹 폰트는 Google Fonts를 사용합니다. 네트워크 연결이 없으면 로컬 그래픽과 시스템 글꼴로 대체됩니다.

## 파일 구성

- `src/App.jsx`: 화면, 이동, 시착 목록·직원 상태·피드백·미션
- `src/components.jsx`: 아이콘, 브랜드 표기, 상품 일러스트, 공통 카드
- `src/data.js`: 시연 상품·매장·재고·추천 규칙
- `src/guide-data.js`: 여러 도시를 섞은 여행 콘텐츠와 공식 관광 안내 출처
- `src/JourneyViews.jsx`: 한국 가이드·쿠폰함·직원 현장 조회 화면
- `src/demo-state.js`: 쿠폰 발급·사용·복원, 옵션별 재고 위치, 현장 조회 규칙
- `src/i18n.js`: 3개 언어 문구
- `src/App.css`: PC·모바일 앱 레이아웃
- `src/index.css`: 공통 스타일
- `public/fitting-qr.svg`: 시연 식별자 QR
